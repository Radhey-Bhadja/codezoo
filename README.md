# Coding Zoo 🦉

> An interactive, visual field guide to 55+ programming languages, paradigms, and tech stacks.

Created by **[Radhey Bhadja](https://github.com/Radhey-Bhadja)**.

---

## ✨ Features

- **Page-Based Experience**: Fixed viewport single-page application with instant tab switching (Explore, Compare, Stack Matcher, About).
- **Interactive 3D Pop-Out Cards**: Tactile cards with bold offset shadows, pastel avatars, and lift hover effects.
- **Deep Stack Matcher**: 4-step architectural diagnostic assessing domain, latency preferences, type safety, and deployment targets.
- **Side-by-Side Comparison**: Select up to 3 languages to compare paradigms, pros, and tradeoffs next to each other.
- **Live Search & Category Filtering**: Instantly search by name, use case, or tag across 12 engineering domains.
- **Zero Heavy Frameworks**: Pure HTML5, modern CSS, and vanilla JavaScript for sub-second load times.

## 🚀 Live Demo & Deployment

To view locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/Radhey-Bhadja/codezoo.git
   ```
2. Open `index.html` in any modern web browser.

To host on **GitHub Pages**:
- Go to **Settings** > **Pages** in this repository.
- Under **Build and deployment**, select **Deploy from a branch**.
- Choose the `main` branch and `/ (root)` folder, then click **Save**.
- Your site will be live at `https://radhey-bhadja.github.io/codezoo/`!
